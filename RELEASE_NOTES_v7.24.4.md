# Quiet Control Center v7.24.4

## 中文

这是 Quiet Control Center 的首个独立仓库发布版本，基于官方 v2rayN 7.24.4。

### 本版内容

- 现代化主窗口与紧凑型响应式布局。
- 国家/地区自动归类并持久保存分组选择。
- 节点列表列显隐设置。
- 延迟测试以及延迟与速度组合测试。
- 每秒刷新延迟、抖动、丢包、代理/直连流量和核心状态。
- 永久软件更新面板。
- 完整客户端功能：节点、订阅、路由、系统代理、TUN、Clash、热键和内核管理。
- 签名完整包更新、逐文件校验、启动确认与失败回滚。

### 安装

下载 `QuietControlCenter-7.24.4-win-x64.zip`，解压到独立目录后运行 `v2rayN.exe`。发布包不包含任何个人订阅、节点数据库或日志。

## English

This is the first standalone Quiet Control Center repository release, based on upstream v2rayN 7.24.4.

### Included

- Modern main window and compact responsive layout.
- Automatic country/region classification with persistent selection.
- Configurable profile-column visibility.
- Latency testing and combined latency/speed testing.
- Per-second latency, jitter, loss, proxy/direct traffic, and core-state updates.
- Persistent Software Update panel.
- Full client functionality: profiles, subscriptions, routing, system proxy, TUN, Clash, hotkeys, and core management.
- Signed complete-package updates with per-file verification, startup acknowledgement, and rollback.

### Installation

Download `QuietControlCenter-7.24.4-win-x64.zip`, extract it into a separate directory, and run `v2rayN.exe`. The archive contains no personal subscriptions, node databases, or logs.
